# Bootstrap 5 → shadcn/ui Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile a custom Bootstrap 5.3 build whose existing components render in the shadcn/ui visual language (light + dark), served as a single CSS file to a PHP/HTML project.

**Architecture:** Vendor Bootstrap 5.3 Sass source in-repo and compile our own build. Three layers: (1) shadcn HSL tokens as runtime CSS custom properties, (2) Bootstrap `--bs-*` variables remapped to those tokens, (3) compile-time Sass for structural scalars + surgical CSS overrides for what variables can't reach. Colors are driven entirely at runtime (never through Sass color math, which would break Bootstrap's `shade-color`/`tint-color` calls).

**Tech Stack:** Bootstrap 5.3 (Sass source, vanilla JS bundle), dart-sass, postcss + autoprefixer, shx (cross-platform npm scripts), PHP built-in server (demo only).

## Global Constraints

- Bootstrap version: **5.3.x** (pin in `package.json`; vendor its Sass source).
- Output is **one** CSS file linked by the app: `dist/css/bootstrap-shadcn.css` (+ `.min.css`). No styling in PHP templates, no inline `<style>`, no per-page CSS.
- Node/npm are **build-time only**. The PHP app serves compiled static assets; it never runs Node at runtime.
- Colors must be driven via runtime CSS variables (`--bs-*` → shadcn tokens) and CSS overrides — **never** by reassigning Bootstrap Sass color variables (breaks `shade-color`/`tint-color`).
- shadcn tokens are HSL **channels** (e.g. `240 5.9% 10%`), consumed as `hsl(var(--token))`. Default `--primary` is neutral near-black — this is intentional (authentic shadcn), not a bug.
- Package name: `bootstrap-shadcn-theme` (not derived from any email domain).
- Platform: Windows. npm scripts must be cross-platform (use `shx`, never bare `rm`/`cp`/`mkdir`).

// Structural (non-color) Sass overrides applied BEFORE Bootstrap is imported.
// Colors are intentionally excluded — they are driven at runtime (see _bs-variable-map).
// These use Bootstrap's !default vars, so setting them here wins.

// Border width — shadcn uses hairline 1px borders
$border-width: 1px;

// Focus ring — shadcn look is a soft ring, no offset shadow stack.
// Geometry only; the ring color is set at runtime in _shadcn-overrides.

$focus-ring-opacity: 1;
$focus-ring-blur: 0;

$box-shadow:    0 1px 3px 0 rgba(0, 0, 0, .1), 0 1px 2px -1px rgba(0, 0, 0, .1);
$box-shadow-lg: 0 10px 15px -3px rgba(0, 0, 0, .1), 0 4px 6px -4px rgba(0, 0, 0, .1);

// Slightly tighter default component paddings to match shadcn density
$input-btn-padding-y: .5rem;
